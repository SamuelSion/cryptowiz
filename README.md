# 🪄 CryptoWiz

Crypto market dashboard — Second Project, Full Stack Web Developer course.
React · TypeScript · Redux · API integrations.

**Live demo:** https://cryptowiz-cfe40.web.app

## What it does

- **Home** — the top 100 coins by market cap, with a live search box (filters
  by name or symbol, case-insensitive, no server round-trip), a collapsible
  "More Info" price panel (USD / EUR / ILS) per coin, and a Switch to track
  up to 5 coins at once. Trying to track a 6th coin opens a dialog asking
  which tracked coin to swap out.
- **Live reports** — two view modes:
  - **All coins (live)** — every tracked coin together on one chart, updated
    once per second from a single batched request (never one request per
    coin per tick). Uses a log-scale Y-axis so coins of very different
    price magnitudes (e.g. BTC at $60k+ next to a stablecoin at $1) stay
    readable on the same chart. Backed by Kraken, with a keyless CoinPaprika
    backup for the handful of coins Kraken doesn't list.
  - **Single coin** — focus on one tracked coin at a time for a clearer
    chart, with the same interval picker in both styles (live, 1m, 5m,
    30m, 1h, 4h, 8h, 12h, 1D, 7D, or 1M):
    - **Line** style plots the price over that interval (live ticks, or the
      closing price of each historical candle for anything longer).
    - **Candlestick** style shows real OHLC candles from Kraken instead
      (needs a real interval, not "live"). 8h/12h/1M aren't native Kraken
      intervals, so those are built by merging smaller candles client-side.
    - Historical data (both styles, anything but "live") comes from Kraken
      first, with CoinGecko as a backup for coins Kraken doesn't list
      (e.g. LEO Token) - only if neither has it does the page say so
      directly instead of failing silently.
- **AI recommendation** — pick one of your tracked coins and get a
  structured verdict (buy / hold / avoid) with a one-line summary, concrete
  strengths and risks pulled from the real numbers, and a closing
  explanation - generated by sending the coin's market data to the OpenAI
  API.
- **About** — project description and author info.

Selected coins and your light/dark preference are both persisted in
`localStorage`, so they survive a page reload. Global state (coin list
cache, tracked coins, theme) lives in Redux so pages never re-fetch data
they already have.

## Environment variables

| Variable                     | Description                                                          |
| ----------------------------- | ------------------------------------------------------------------------ |
| `VITE_OPENAI_API_KEY`         | OpenAI API key. Required for the AI recommendation page.             |
| `VITE_COINGECKO_API_KEY`      | CoinGecko free Demo key. Required (home page, More Info, AI page).   |
| `VITE_CRYPTOCOMPARE_API_KEY`  | CryptoCompare / CoinDesk Data key. Optional — enables true 1s updates. |

`.env` is git-ignored — never commit your real keys. Because this is a
client-side React app, keys ship inside the built bundle; that's an
accepted limitation for this course project, not something to reuse as-is
in a production app with paying users.

> **Note on CoinGecko — required, and genuinely free:** the home page,
> More Info panel, and AI page all need it; there's no way to swap it out
> for one of the other providers below, since only CoinGecko gives coin
> names/icons/market data here. The Demo API key costs nothing and never
> asks for a credit card (don't confuse it with CoinGecko's separate
> *consumer* "Premium" subscription for the coingecko.com website/app -
> that's a different product from the free developer API). The fully
> keyless public endpoint still works too, but it's shared across everyone
> hitting it from the same network and gets rate-limited fast — that's the
> #1 cause of an empty coin grid or a "network error" on the home page.
> Get a free Demo key (no credit card):
> [coingecko.com/en/api/pricing](https://www.coingecko.com/en/api/pricing)
> → "Create Free Account" → Developer Dashboard → API Keys → **+ Add New
> Key**. Paste it into `.env` as `VITE_COINGECKO_API_KEY` and every
> CoinGecko call in the app automatically starts using it.

> **Note on CryptoCompare:** it gives true 1-second live price updates when
> configured, but requires applying for a free "Personal" account (manual
> approval, and capped on *total lifetime calls* rather than a renewing
> monthly quota like CoinGecko). If you'd rather skip that setup step,
> leave `VITE_CRYPTOCOMPARE_API_KEY` empty — the app automatically falls
> back to Kraken, which needs no signup at all and still updates every
> second for the coins it lists.

## APIs used — full hierarchy

Every feature's data source(s), in priority order, with what triggers a
fallback to the next one:

| Feature | 1st (primary) | 2nd | 3rd | Falls back when... |
| --- | --- | --- | --- | --- |
| Home page (coin list) | **CoinGecko** `/coins/markets` | — | — | No fallback — required, see note above |
| More Info panel | **CoinGecko** `/coins/<id>` | — | — | No fallback — required |
| AI recommendation | **CoinGecko** `/coins/<id>` (data) + **OpenAI** `/v1/chat/completions` (analysis) | — | — | No fallback — required |
| Live report, all coins | **CryptoCompare** `/data/pricemulti` | **Kraken** `/public/Ticker` | **CoinPaprika** `/tickers` | CryptoCompare: no key configured. Kraken: any tracked coin isn't listed there |
| Live report, single coin ("live") | same 3-tier chain as above, scoped to one coin | | | same as above |
| Historical line / Candlesticks | **Kraken** `/public/OHLC` | **CoinGecko** `/coins/<id>/ohlc` | — | Kraken: coin not listed there (e.g. LEO Token) |

Why this order and not something simpler:

- **CoinGecko is never used for live/historical price polling**, even
  though it *could* serve all of this alone, because that would burn its
  10,000-calls/month quota on continuous polling and starve the three
  pages above that have no fallback and genuinely need it.
- **CryptoCompare is tried first for live prices** (true 1s updates) but
  is entirely optional - skipped instantly, no network call, if you don't
  configure a key. See the note above on why it's not worth the signup
  friction for a course project.
- **Kraken is the practical default** for both live prices and
  historical/candlestick data: keyless, no account, no cap, real exchange
  data. It only covers coins actually traded there (~73% of the current
  top-100).
- **CoinPaprika backs up live prices**, and **CoinGecko backs up
  historical/candlestick data**, for the ~27% of coins Kraken doesn't
  list — different providers on purpose, again to avoid spending
  CoinGecko's limited quota on the continuously-polled live feature.

## APIs used — endpoint reference

**Coin data (required, powers Home / More Info / AI pages) — CoinGecko.**
This can't be swapped out for one of the other providers below: the home
page, the More Info panel, and the AI recommendation page all need it for
coin names, icons, market caps, and other details that only CoinGecko
provides here. It's genuinely free (Demo plan: no credit card, 10,000
calls/month) - see the note above if you're hitting rate limits.

- `/coins/markets` — top 100 coins for the home page
- `/coins/<id>` — single-coin details (More Info panel, AI page)

**Live prices (reports page only) — Kraken, CryptoCompare, CoinPaprika.**
CoinGecko is deliberately *not* used here, to keep its quota free for the
two required pages above. Three providers, tried in this order:

**AI recommendation — OpenAI** `/v1/chat/completions`.
